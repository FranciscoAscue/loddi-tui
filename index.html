THE WORKFLOW

Everything around the writing, kept quiet.

01 / DRAFT

Markdown stays Markdown

Open a single .md file or a whole book folder. The source editor highlights Markdown and fenced code by language.

02 / ORGANIZE

A manuscript that makes sense

Cover, front matter, chapters and an automatically generated contents file. Search instead of scrolling through a long tree.

03 / REFERENCE

Citations at hand

Import BibTeX exported from Zotero, browse references, and insert single or multiple citations from the editor.

04 / PUBLISH

Export when ready

Create EPUB with Pandoc, or PDF with Pandoc and Typst. Optional tools can be installed locally on demand.

BUILT FOR THE KEYBOARD

One prompt. The whole manuscript.

Search files from the launcher, open commands with /, and use ? when you need a reminder. Editing, references and export stay one keystroke away.
