INSTALL FROM GITHUB

Copy the command for your system.

These commands install the current source package. They require Node.js 22.20 or newer and npm. The npm registry package and portable downloads are not available yet.

Linux / macOS

Read the installer first. It builds the package and installs it globally without sudo.

curl -fsSL https://raw.githubusercontent.com/FranciscoAscue/loddi-tui/master/scripts/install.sh | bash
loddi --version

Windows PowerShell

Install Git, Node.js and npm first. Package the checkout, then install the generated tarball.

git clone https://github.com/FranciscoAscue/loddi-tui.git
cd loddi-tui
npm ci
npm pack --ignore-scripts
npm install --global .\loddi-tui-0.1.0.tgz
loddi --version

The tarball filename changes with the package version. Use the filename printed by npm pack. For portable archives and troubleshooting, open the installation guide.

AVAILABLE NOW

From Markdown to manuscript.

01 / WRITE

Edit plain Markdown

Open any .md file. The editor highlights Markdown and fenced code, and inserts code, Mermaid, math or images from one menu.

02 / ORGANIZE

Keep the book in order

Create cover, sections and chapters. Search long manuscripts, reorder documents and regenerate SUMMARY.md. Unstructured Markdown keeps its filename.

03 / CITE

Use your bibliography

Import BibTeX from Zotero, edit references and insert one or several citations without leaving the editor.

04 / EXPORT

Build EPUB or PDF

Install Pandoc and Typst when needed. Check manuscript issues before export. Loddi also checks for updates and asks before installing one.

BUILT FOR THE KEYBOARD

Search, then act.

Search documents in the launcher. Press / for commands or ? for shortcuts. Press Ctrl+P inside the editor to insert Markdown blocks or open the optional Codex assistant.
