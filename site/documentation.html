DOCUMENTATION / 0.1

Install. Write. Export.

Start with a Markdown file or a folder. Loddi keeps your source files editable outside the TUI.

Installation

Install the current package from GitHub. You need Node.js 22.20 or newer and npm. On Windows, you also need Git. Do not use npm install -g loddi-tui until the package is published to the npm registry.

Linux or macOS: review the installer script, then run:

curl -fsSL https://raw.githubusercontent.com/FranciscoAscue/loddi-tui/master/scripts/install.sh | bash
loddi --version

Windows PowerShell: clone, build and install the package archive:

git clone https://github.com/FranciscoAscue/loddi-tui.git
cd loddi-tui
npm ci
npm pack --ignore-scripts
npm install --global .\loddi-tui-0.1.0.tgz
loddi --version

Use the archive filename printed by npm pack if the version is no longer 0.1.0. The shell script requires curl and tar; it builds from master, then installs the package without sudo. Neither route installs Node.js. If loddi is not found after installation, check that npm's global binary directory is on PATH. See the full installation guide for troubleshooting and removal.

Portable downloads

The project can build platform-specific .tar.gz archives with Node.js included. A portable build runs without a separate Node or npm installation: use ./loddi on Linux/macOS or .\loddi.cmd on Windows.

Download Loddi v0.1.0 for Linux x64/ARM64, macOS Intel/Apple Silicon or Windows x64. Download its adjacent .sha256 file and check it before extraction. Read the portable guide for commands and limitations.

Updates

When a newer portable release is available, the TUI asks before downloading it. You can also open /update or use the terminal:

loddi update --check   # check only
loddi update           # ask before installing
loddi update --yes     # confirm in a script

The updater verifies the archive and installs it beside the current version. Restart using the launcher path it prints. It does not replace an npm-global installation or touch manuscript files. Version 0.1.0 is currently the latest release, so it will not offer itself as an update. See the update guide.

Navigation and commands

Type to search documents. Use ↑/↓ or Page Up/Page Down to move through long lists; press Enter to open. Type / for commands and ? for shortcuts.

Create chapters with Ctrl+N, sections with Ctrl+T and a cover with Ctrl+O. Rename the selected document with Ctrl+E. Use Alt+↑/Alt+↓ to reorder it; Loddi keeps the moved item selected and shows its new position. Only numbered files in chapters/ are renamed. Other Markdown filenames stay as they are.

Quick start

Create a book folder, then open it:

loddi init ./my-book --title "My book"
loddi ./my-book

Already have Markdown files? Open one directly, or index a folder without moving its files:

loddi ./notes.md
loddi init ./existing-folder --adopt
loddi ./existing-folder

init --adopt creates book.yaml and SUMMARY.md. It stops if SUMMARY.md already exists, so Loddi does not overwrite it.

Editor

The editor shows Markdown source with syntax highlighting, including language-aware fenced code. Press Ctrl+P to insert headings, lists, code, Mermaid, LaTeX math or images. Select with arrows and Enter, or use the option letter. You can also focus or remove a Markdown block from this menu.

Ctrl+SSave
Ctrl+PInsert Markdown
Ctrl+FFind
Ctrl+IInsert citation
Ctrl+DelDelete next word
Ctrl+← / →Move by word
PgUp / PgDnMove one editor page
MouseClick to position; wheel to scroll
TabIndent two spaces
Ctrl+QBack to launcher

The appearance of non-English text depends on your terminal font. Manuscript files are UTF-8.

Optional Codex assistant

Loddi works without AI. To enable this feature, install the Codex CLI separately, then sign in. If Node.js and npm are installed, run:

npm install -g @openai/codex
codex login
codex login status

In the Markdown editor, press Ctrl+P, then A. Insert is the default mode; Tab switches to Edit block or Chat. Describe the Markdown you want, such as a fenced code example, Mermaid diagram or display LaTeX. Loddi sends the current block or line to Codex in a read-only temporary workspace, not the whole manuscript. It shows a proposal before changing the unsaved editor buffer. Press Enter to apply a proposal and Ctrl+S to save. Chat answers do not edit the document.

If you are not signed in, Loddi can start device-code authentication and show the URL and code. This method may need to be enabled for your account or workspace; if it is unavailable, run codex login in a separate terminal and recheck in Loddi. Loddi does not ask for your password or API key. Review generated Markdown and the exported layout before publishing. See Codex authentication for sign-in options.

Citations

Export references from Zotero as BibTeX. In Loddi, open /references and import the .bib file. You can browse and edit entries there. In the editor, Ctrl+I searches references; Tab collects multiple citations, Ctrl+T switches citation form, and Enter inserts them.

Direct Zotero account synchronization is not implemented.

Publishing

loddi tools status
loddi tools install pandoc
loddi tools install typst
loddi export epub ./my-book
loddi export pdf ./my-book

Run /install pandoc and /install typst inside the TUI if you prefer. EPUB uses Pandoc. PDF uses Pandoc and Typst by default. Loddi installs managed tools in user data, not system directories. Use /fonts to choose a PDF font and /review to check the manuscript before export.

Project files

A project is a normal folder. book.yaml tracks document order, and Loddi regenerates SUMMARY.md when that order changes. Cover, contents, front matter and chapters are separate Markdown files. Images live under assets/; references live under bibliography/. You can also open a single .md file without a project.

Current limits

The TUI highlights Mermaid blocks but does not render their diagrams. The terminal does not display images or full LaTeX. Use the exported file to check final layout. Zotero account sync is not available; import BibTeX instead. The npm registry package is not published; use the portable GitHub Release or install from source.
