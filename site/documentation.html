DOCUMENTATION / 0.1

Make room for the manuscript.

Loddi works with ordinary Markdown files. Use it for one document, or initialize a folder to manage a complete book.

Installation

Loddi requires Node.js 22.20 or newer and targets Windows, macOS and Linux. The package is not yet published on npm. Clone the repository and install from source:

git clone https://github.com/FranciscoAscue/loddi-tui.git
cd loddi-tui
npm install
npm run build
npm link

Then run loddi --help. From a checkout without npm link, use node dist/cli.js instead. Pandoc and Typst are optional until export. The platform installation guide covers PowerShell, updates and removal.

Navigation and commands

The launcher searches the manuscript without filling the screen with a file tree. Use ↑ and ↓ to move through results, then Enter to open one. Type / for commands and ? for contextual shortcuts. The command list scrolls when a book has many chapters.

Commands cover creating and renaming manuscript files, reviewing the book, managing references and fonts, checking/installing publishing tools, and exporting. Use the on-screen command list for the exact options available in your current context.

Quick start

loddi init ./my-book --title "My book"
loddi ./my-book

Type to search your manuscript. Type / to reveal commands, or ? for shortcuts. Open an existing Markdown file directly with loddi ./notes.md; it does not need a project.

To index existing Markdown files in a folder without moving them, use loddi init ./folder --adopt. This creates the book manifest and contents file; it stops if a SUMMARY.md already exists.

Editor

The editor shows highlighted Markdown source. Fenced code gets language-aware colors. Press Ctrl+P for a compact insertion menu: headings, bold, lists, code, Mermaid, LaTeX math and images. Choose with arrows and Enter or the menu letter. The same menu lets you focus or remove a Markdown block.

Ctrl+SSave
Ctrl+PInsert Markdown
Ctrl+FFind
Ctrl+IInsert citation
Ctrl+DelDelete next word
Ctrl+← / →Move by word
PgUp / PgDnMove one editor page
MouseClick to position; wheel to scroll
TabIndent two spaces
Ctrl+QBack to launcher

The appearance of non-English text depends on your terminal font. Manuscript files are UTF-8.

The optional A entry in Ctrl+P opens a Codex assistant. Install the Codex CLI separately; Loddi checks its sign-in status and, if needed, Enter starts browser-based device authentication. Loddi displays the URL and code but never handles your password or API key. Insert is the default mode; Tab switches to Edit block or Chat. Codex runs read-only on a temporary excerpt and shows a proposal for review before Loddi changes the unsaved buffer. Mermaid, fenced code, and display LaTeX can be generated; review their syntax and rendered output before publishing.

Citations

Export a Zotero library as BibTeX and import the .bib file through /references. Loddi stores references in the project bibliography. In the editor, Ctrl+I searches entries; Tab collects multiple citations, Ctrl+T switches narrative and parenthetical form, and Enter inserts them.

Direct Zotero account synchronization is not implemented.

Publishing

loddi tools status
loddi tools install pandoc
loddi tools install typst
loddi export epub ./my-book
loddi export pdf ./my-book

The same operations are available inside the launcher as /install pandoc, /install typst, /export epub and /export pdf. EPUB uses Pandoc; PDF also uses Typst by default. Managed tools are installed in user data, not system directories. Use /fonts to choose a font for PDF output. Export opens its own terminal screen, so status and errors remain visible.

Project files

A project is a normal folder. The book.yaml manifest tracks the manuscript; SUMMARY.md is regenerated when its structure changes. Markdown chapters, front matter, cover, bibliography and images remain readable in other tools. Loddi separates cover, contents and manuscript units in publication output.

Current limits

Mermaid blocks are highlighted in the editor but exported as code unless an external preprocessor is configured. The terminal does not render images or full LaTeX; final layout is handled during export. Cross-platform CI is configured, but its remote results and a published npm package are still pending.

For development details and current status, read the README and plan.
